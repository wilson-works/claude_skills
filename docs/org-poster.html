Execution model: in this environment a sub-agent can’t spawn another sub-agent, so the top-level session does all the spawning. The chain above is the accountability model, not a call stack — review gates and named ownership stay; only the spawn-theater is dropped.

The parallel loop — /workday

Four loops at once, each in its own git worktree (zero write collisions), merged in dependency order. /workday-watch is an optional fifth session that keeps them honest in real time.
