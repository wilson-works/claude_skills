# Premortem Skill — Install Instructions

## Setup

1. Drop this folder anywhere in your repo
2. Paste this into Claude Code:

```
Install the Premortem skill: read the SKILL.md file from the premortem folder in this repo, then create the folder ~/.claude/skills/premortem/ and copy SKILL.md there. After copying, confirm the skill is installed by listing the contents of ~/.claude/skills/premortem/. Do not modify the file.
```

3. Restart Claude Code
4. Say "premortem this" followed by any plan, launch, hire, or decision you want pressure-tested

## When to use it

The premortem assumes your plan already failed 6 months from now and works backward to find every reason why. Best used before any commitment where the cost of being wrong is high — product launches, pricing changes, hires, partnerships, strategy pivots.

It is NOT the LLM Council. The council gives multiple perspectives on a decision right now. The premortem sends Claude into the future where the decision already failed and explains how it died. Different mechanism, different output.
