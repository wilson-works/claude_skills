# LLM Council Skill -- Install Instructions

## Setup

1. Drop this folder anywhere in your repo
2. Paste this into Claude Code:

```
Install the LLM Council skill: read the SKILL.md and article.md files from the llm-council folder in this repo, then create the folder ~/.claude/skills/llm-council/ and copy both files there as SKILL.md and article.md. After copying, confirm the skill is installed by listing the contents of ~/.claude/skills/llm-council/. Do not modify the files.
```

3. Restart Claude Code
4. Say "council this" followed by any decision you're wrestling with
